## ◈ Quem somos

A **Trooppinen Valas** é uma empresa dedicada a criar ferramentas de segurança acessíveis para servidores Linux de pequeno e médio porte.

Acreditamos que proteger um servidor não deveria exigir anos de estudo. Por isso criamos linguagens simples, em português, que qualquer pessoa consegue usar.

---

## ◈ Nosso projeto

### 🐋 Trooppinen Valas — Linguagem de Defesa

Uma linguagem de programação interpretada que protege servidores Linux contra ataques cibernéticos.

| Recurso | Descrição |
|:---|:---|
| **Alvo Móvel** | Embaralha portas automaticamente |
| **Modo Fantasma** | Esconde processos do sistema |
| **Aprendizado** | Cria novas regras sozinho |
| **Colmeia P2P** | Compartilha defesas entre servidores |
| **Watchdog** | Reinicia o motor se cair |

**Repositório:** [github.com/ARTHUR500-12/trooppinen-valas](https://github.com/ARTHUR500-12/trooppinen-valas)
